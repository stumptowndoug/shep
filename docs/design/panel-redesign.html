Shep — panel redesign options

Two directions for each of Settings, History, Usage and Ports. A is quieter and more structured (fewer boxes, real controls, one thing per row). B is denser and more data-forward (cards, tables, split views). Mix and match — each panel can take a different direction.

Category rail replaces one 9-section scroll Real controls — switches, segments, steppers instead of On/Off pill pairs Each row explains itself — description under the label, no hover tooltips Search jumps to any setting
